# 跨模型兼容与降级

## 通用层

核心卡是普通 UTF-8 Markdown，不要求工具调用、插件语法、隐藏记忆或特定模型能力。
目标模型没有安装 Skill 时，把完整卡片贴入新会话，并发送卡内“新会话首条提示词”。

## 能力分级

- 只有聊天输入：使用 `QUICK + text + conversation`；路径可空，外部状态保持未知。
- 能读附件但不能访问原机器：附卡和最少证据副本；用 `<PROJECT_ROOT>`、`<HOME>`
等别名，来源会话标识按分享需要脱敏，无法核验的证据降为 `UNVERIFIED`。
- 能访问同一项目：使用 `VERIFIED + repo + mixed/external`，先复核高影响证据。
- 能安装 Skill：可使用生成器、校验器、归一化、分块和脱敏脚本，但卡片仍应独立可读。

## 语言

默认中文。用户明确用英文或要求英文交接时使用英文模板；其他语言可翻译可见字段，但要
保留状态码和协议字段。当前机器校验器只内置 `zh-CN` 与 `en` 结构。

## 路径与隐私

同机私有交接可以保留绝对路径；跨机器或公开分享优先仓库相对路径和别名。先运行
`redact_handoff.py`，再人工复核。不要把用户名、邮箱、会话 ID、访问令牌或私钥当作
“方便接手”的必要信息。

## 诚实边界

“跨模型可读”不等于“每个平台的历史导出格式都已实测”。未知导出先转换为
`role/content` JSON 或纯文本；无法证明覆盖完整时使用 `PARTIAL`。
